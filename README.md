# Pandas Data Cleaning Project

This repository contains a Jupyter Notebook that demonstrates how to clean and preprocess messy real-world datasets using **Python** and **Pandas**.

## Notebook

The main notebook is:
- [`DataCleaningPandasProject.ipynb`](https://github.com/lizz234/Pandas-Data-Cleaning/blob/main/DataCleaningPandasProject.ipynb)

It walks through common data cleaning steps, including:
- Importing Excel files with `pandas.read_excel()`
- Handling missing values (`NaN`)
- Standardizing column values (e.g. `Yes`/`No`, phone numbers)
- Splitting and extracting address fields
- Removing duplicates
- Fixing inconsistent formatting

## Tools Used

- Python 3.x
- Jupyter Notebook
- Pandas
- Excel as the data source (`.xlsx`)

## Sample Data

The project uses a sample Excel file: `Customer Call List.xlsx`, which includes fictional customer information such as names, phone numbers, addresses, and contact preferences.

> Note: You can replace this with your own dataset to try similar cleaning techniques.
